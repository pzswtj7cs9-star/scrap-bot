# بوت الأسهم الأمريكية الحلال — Telegram

بوت تليجرام متخصص في أسهم السوق الأمريكي الشائعة التصنيف كحلال وفق معايير AAOIFI المتعارف عليها (نشاط مباح + نسب الدين والفائدة).

عند ظهور إشارة فنية **عالية التوافق (85 فأعلى + تأكيد لحظي)** يرسل أقوى 5 أسهم فقط في اليوم:

- منطقة شراء
- وقف خسارة
- ثلاثة أهداف
- درجة الإشارة من 100
- أسباب التوافق والمخاطر

## حقيقة مهمة قبل التشغيل

لا يوجد نظام تداول بنسبة خطأ ضعيفة جداً مثل 99%.  
هذه النسبة غير واقعية في الأسهم.

ما يفعله البوت بدل ذلك:

- يسكت أغلب الوقت
- لا ينبّه إلا إذا اجتمعت عدة شروط معاً (اتجاه + RSI + MACD + حجم + موقع سعري)
- الحد الافتراضي للإشارة التلقائية: **85/100 + تأكيد لحظي على 5 دقائق**
- سقف يومي: **5 أسهم فقط**
- لا تُرسل دفعة واحدة: **سهم واحد كل 90 دقيقة**، وهو الأقوى في تلك اللحظة

هذا يقلل الإشارات العشوائية، لكنه **لا يلغي الخسارة**.

التصنيف الشرعي أيضاً يتغير كل ربع سنة. القائمة هنا نقطة بداية، وليست فتوى.

## 1) إنشاء البوت في تليجرام

1. افتح [@BotFather](https://t.me/BotFather)
2. أرسل `/newbot`
3. اختر اسماً مثل: `Halal US Stocks`
4. اختر يوزر مثل: `halal_us_alerts_bot`
5. انسخ الـ Token

لمعرفة آيدي حسابك أرسل أي رسالة لـ [@userinfobot](https://t.me/userinfobot)

---

## 2) التجربة على جهازك

```bash
python -m venv .venv
source .venv/bin/activate   # ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

عدّل `.env`:

```
BOT_TOKEN=التوكن_هنا
OWNER_CHAT_ID=آيدي_حسابك
MIN_SCORE=85
DAILY_MAX_ALERTS=5
ALERT_EVERY_MINUTES=90
LIVE_SCAN_SECONDS=60
EARNINGS_DAYS=2
```

ثم:

```bash
python main.py
```

افتح البوت في تليجرام وأرسل `/start`

---

## 3) الرفع على Render (تندر / ريندر)

Render مناسب لهذا البوت.

### أ) ارفع المشروع على GitHub

أنشئ مستودع جديد وارفع كل ملفات هذا المجلد.

### ب) أنشئ Web Service

1. ادخل [render.com](https://render.com) وسجّل بـ GitHub
2. **New +** → **Web Service**
3. اختر المستودع
4. الإعدادات:

| الحقل | القيمة |
|---|---|
| Name | halal-us-stock-bot |
| Runtime | Python 3 |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `python main.py` |
| Instance | Free أو Starter |

### ج) Environment Variables

من تبويب Environment أضف:

- `BOT_TOKEN` = توكن BotFather
- `OWNER_CHAT_ID` = آيدي حسابك
- `MIN_SCORE` = `80`
- `SCAN_INTERVAL_MINUTES` = `45`
- `PYTHON_VERSION` = `3.12.7`

ثم Deploy.

### ملاحظة عن الخطة المجانية

الخطة المجانية في Render قد تنام بعد عدم الاستخدام.  
للبوت الشخصي أفضل:

- خطة Starter إذا قدرت
- أو Web Service + خدمة خارجية توقظ الرابط كل 10 دقائق
- أو Background Worker مع نفس أمر التشغيل `python main.py`

البوت يفتح منفذ `PORT` ويرد `{"status":"ok"}` حتى يقبل Render تشغيله كـ Web Service.

## 4) الأوامر

| الأمر | الوظيفة |
|---|---|
| `/start` | البداية |
| `/analyze NVDA` | تحليل سهم |
| `NVDA` | تحليل مباشر بكتابة الرمز |
| `/scan` | مسح الأسهم الأساسية |
| `/list` | قائمة الحلال المعتمدة هنا |
| `/watch AMD` | إضافة للمراقبة |
| `/subscribe` | تفعيل التنبيه التلقائي |
| `/unsubscribe` | إيقاف التنبيه |

التنبيه التلقائي يعمل تقريباً أثناء جلسة السوق الأمريكي (نحو 4:30 م إلى 11 م بتوقيت الرياض، أيام العمل).

---

## 5) كيف تُحسب منطقة الشراء والوقف والأهداف؟

- **الاتجاه:** السعر ومتوسط 50 فوق متوسط 200
- **الزخم:** RSI بين منطقة صحية، وMACD داعم
- **الحجم:** أعلى من متوسط 20 يوم
- **الشراء:** قرب متوسط 20 أو قاع الأيام الأخيرة، لا مطاردة امتداد
- **الوقف:** قاع هيكلي أو 1.8 ATR (أيهما أحمى ضمن حدود معقولة)
- **الأهداف:** 1.6R و 2.6R و 4R تقريباً

ارفع `MIN_SCORE` إلى 85 إذا تريد إشارات أقل وأشد.

- تقرير أسبوعي الجمعة بعد الإغلاق أو عبر `/weekly`
